專案html專案5-自動排班工具研究

## 採購時程日曆
排採購時程用的日曆工具：點一下節點（上網公告、開標、決標…），再點日期，後面的節點就依「相隔幾天」自動推算；長條週曆可直接用 A4 直式列印。

### 三種版本
| 版本 | 用途 | 怎麼拿到 |
| --- | --- | --- |
| Claude 版 | 手機與電腦都能開，案件存在雲端自動同步 | https://claude.ai/artifact/WsUECg1icL8mDwXuXG6xUp |
| 單檔版 | 沒網路的辦公室電腦用：一個 .html 檔，資料包在裡面，點兩下就能開、能印 | `dist/採購時程日曆.html`，或在任何版本按「更多 → 匯出 → 單檔」 |
| 網頁版 | 開發用，`calendar.html` 加 `calendar.css`、`calendar.js`、`holidays-data.js` | 本機開啟 |

`python3 build.py` 會把網頁版合成 `dist/採購時程日曆.html`（內建 `seed.json` 的案件）與 `dist/artifact.html`（Claude 版，案件來自雲端）。

### 功能
- 上方「動態島」列出各節點的日期；點一下節點（或格子裡的標籤），再點下方任一日期，就把該節點設在那天；也可以直接拖曳格子裡的標籤到別天
- 改某個節點的日期只會調整它與前一節點的相隔天數並帶動後面的節點，前面的節點不動；要整個時程平移就改第一個節點
- 分上午、下午的節點：點格子上半部是上午、下半部是下午；相隔天數可用半天為單位（0.5）：上午加半天為同日下午，下午加半天為隔天上午
- 每個節點可設定相隔天數、日曆天或工作天、時段、遇假日是否順延與說明；中間節點可拖曳排序，也能插入或刪除節點
- 多個案件各自保存，動態島左上角或底部「案件」可切換、新增、複製、刪除
- 「更多 → 匯出」：單檔（.html，含資料）、.json 備份、行事曆 .ics（匯入 Google 日曆，不設提醒）；「匯入檔案」可讀 .json 備份或單檔，遇到同一案件會問要覆蓋、另存或略過
- 週曆預設從民國 114 年 1 月開始（可改起始月份），也可多顯示前後月份；年份可切換民國或西元
- 外觀可跟隨系統或固定白天、黑夜
- 每段期間的每一天都標示「第 N 天」，滑過日期會顯示距離各節點幾天；天數可選次日起算或當日起算
- 工作天扣除週末與國定假日（內建 2024–2027 年政府行政機關辦公日曆表，其他年份線上載入），補行上班日算工作天
- 列印時第一頁印出時程摘要表；流程設定可記錄採購金額級距

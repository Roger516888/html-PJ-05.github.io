## 賽道倒數計時（`countdown/`）

賽車轉播風格的倒數計時工具，純 HTML／CSS／JavaScript，不需建置。
發佈後的網址：`/countdown/`（例如 `https://roger516888.github.io/countdown/`）。

- **計時器**：快速預設（專注、休息、簡報…）或自訂 1 秒～99:59:59；開始／暫停／重設。
- **目標日期**：倒數到指定的日期時間，顯示天／時／分／秒，設定會存在瀏覽器。
- **起跑燈**：最後 5 秒由 1 盞亮到 5 盞，歸零全部熄滅並響起提示音。
- **旗號**：綠旗（計時中）、黃旗（最後一分鐘，短計時則取 25%）、紅旗（暫停）、方格旗（時間到）。
- **分段進度**：S1／S2／S3 三段，走完的分段轉紫色。
- **快捷鍵**：空白鍵 開始／暫停、`R` 重設、`F` 全螢幕、`M` 音效開關。
- 計時以「結束時刻」為準，分頁在背景也不會失準；計時中會保持螢幕常亮（瀏覽器支援時），並把剩餘時間顯示在分頁標題。

## 採購時程日曆（calendar.html）
排採購時程用的日曆工具，可直接用 A4 直式列印：
- 上方「動態島」列出各節點（上網公告、結標、開標、POC、評選、決標、履約期限）的日期；點一下節點，再點下方任一日期，就把該節點設在那天，其他節點自動往前後推算
- 每個節點可設定「與前一節點相隔幾天」、日曆天或工作天、時段（全天／上午／下午）、遇假日是否順延與說明；中間節點可拖曳排序，也能在任一列下方插入或刪除節點
- 相隔天數可用半天為單位（0.5）：上午加半天為同日下午，下午加半天為隔天上午，例如上午開標、下午 POC 說明會
- 週曆一律從本月開始顯示（節點較早時從節點月份開始），也可按「多顯示前／後一個月」延伸範圍
- 連續週曆長條：每段期間的每一天都標示「第 N 天」（例如履約第 1～180 天），滑過日期會顯示距離各節點幾天
- 天數起算方式可選「次日起算（始日不算入）」或「當日起算」
- 工作天扣除週末與國定假日（線上載入政府行政機關辦公日曆表，ruyut/TaiwanCalendar），補行上班日算工作天
- 案名、備註與流程設定存在瀏覽器 localStorage；列印時會在第一頁印出時程摘要表

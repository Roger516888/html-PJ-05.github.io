## 動態日曆（calendar.html）
獨立的手機版日曆小工具，版面依手繪示意圖設計：
- **動態島**：平常顯示月份與時間；點日期時展開顯示當天的農曆、節日與行程，4 秒後自動收合
- 星期一開頭（一～日），日期以圓圈顯示，含農曆與台灣國定假日／補假／補班
- **上下滑動**切換月份（桌機可用滑鼠滾輪或方向鍵）
- 底部功能列四個按鈕：今天、新增、行程、外觀（深色模式）
- 行程存在瀏覽器 localStorage；假日資料線上載入政府行政機關辦公日曆表（ruyut/TaiwanCalendar），失敗時僅標示週末
